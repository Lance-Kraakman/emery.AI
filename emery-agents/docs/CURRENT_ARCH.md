 How Plans Are Generated                                                                                                                                                                                        
                                                                                                                                                                                                                
 Flow 1: Monolithic Planning (Default)                                                                                                                                                                          
                                                                                                                                                                                                                
 ExecutionCoordinator.create_plan()                                                                                                                                                                             
     │                                                                                                                                                                                                          
     ▼                                                                                                                                                                                                          
 PlanService.generate_plan(use_domain_routing=False)                                                                                                                                                            
     │                                                                                                                                                                                                          
     ▼                                                                                                                                                                                                          
 PlanGenerator.generate()                                                                                                                                                                                       
     │                                                                                                                                                                                                          
     ├── 1. Resolve model via model_provider                                                                                                                                                                    
     │                                                                                                                                                                                                          
     ├── 2. Create planner managed agents:                                                                                                                                                                      
     │       • research_agent (if api_key + org_id)                                                                                                                                                             
     │       • conversation_history_lookup_agent (if history)                                                                                                                                                   
     │                                                                                                                                                                                                          
     ├── 3. Get ACE context:                                                                                                                                                                                    
     │       • strategy_guidance = StrategyAccumulationService.get_relevant_strategies()                                                                                                                        
     │       • recent_tool_results = extract from conversation_history                                                                                                                                          
     │                                                                                                                                                                                                          
     ├── 4. Render Jinja2 template:                                                                                                                                                                             
     │       render_template("planning/interactive_planner.j2",                                                                                                                                                 
     │           task=instructions,                                                                                                                                                                             
     │           tools=tools,                                                                                                                                                                                   
     │           managed_agents=[agent.to_dict() for agent in agents],                                                                                                                                          
     │           has_research_agent=True/False,                                                                                                                                                                 
     │           strategy_guidance=strategy_guidance,      # ACE                                                                                                                                                
     │           recent_tool_results=recent_tool_results,  # ACE                                                                                                                                                
     │       )                                                                                                                                                                                                  
     │                                                                                                                                                                                                          
     ├── 5. Run ToolCallingAgent:                                                                                                                                                                               
     │       • LLM may call research_agent to gather context                                                                                                                                                    
     │       • LLM calls submit_plan() with goal, steps, context                                                                                                                                                
     │                                                                                                                                                                                                          
     └── 6. Parse captured plan into Plan object
