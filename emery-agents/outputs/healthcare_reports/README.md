# Healthcare Reports Output Directory

This directory contains healthcare reports generated by the DRCare Healthcare Report Writer Agent.

## Directory Structure

```
outputs/healthcare_reports/
├── aged_care/           # Residential aged care placement reports
├── life_plans/          # Comprehensive life planning documents  
├── executive_summaries/ # Concise executive summary reports
└── README.md           # This file
```

## Report Naming Convention

Reports are saved with the following naming pattern:
- **Aged Care Reports**: `{ClientName}_aged_care_report_{YYYYMMDD}.md`
- **Life Plans**: `{ClientName}_life_plan_{YYYYMMDD}.md`  
- **Executive Summaries**: `{ClientName}_executive_summary_{YYYYMMDD}.md`

## Report Format

All reports include:
- Metadata header with generation timestamp and client information
- Professionally formatted content in Markdown
- Structured sections based on DRCare templates
- Compliance with healthcare documentation standards

## Generated By

**DRCare Healthcare Report Writer Agent**
- Agent ID: 8
- Capabilities: residential_aged_care_report, life_plan_report, executive_summary_report
- Tools: document_generator, file_writer, file_reader, template_reader
